# Project Detail - Smart Solar & Security Solutions

## Project Overview
This project involves migrating and elevating the Google Sites website for **Smart Solar & Security Solutions** (Islamabad, Pakistan) into a professional, mobile-responsive, modern Web application built using Next.js. 

We are replacing the default hair salon template sections present on their original Google Sites with clean, professional, domain-relevant services and client testimonials.

## Technical Specifications
* **Framework**: Next.js v16.2 (App Router)
* **Runtime**: React v19
* **Styling**: Tailwind CSS v4
* **Language**: TypeScript / JavaScript
* **Typography**: Geist Sans & Geist Mono (Tailwind theme integration)
* **Theme Colors**:
  * **Primary**: Deep Solar Blue (`#08499D` / HSL `215 90% 32%`)
  * **Secondary / Solar Accent**: Gold Amber (`#F59E0B` / HSL `38 92% 50%`)
  * **Backgrounds**: Slate Grays / White with modern Glassmorphism (semi-transparent backdrops with backing blurs).

## Site Architecture (Routes)
1. `/` (Home): Overview of services, primary CTA buttons (Book Site Visit & WhatsApp Now), full-service experience message.
2. `/services` (Services): Details of Hybrid Solar Inverters, Lithium Batteries, Solar Panel Structures, Net Metering options, and CCTV setups.
3. `/about` (About): Detail history since 2010, irfan Ahmad's vision, team structure, list of technologies supported (GoodWe, lithium storage, standard HD cameras).
4. `/testimonials` (Testimonials): Customer satisfaction quotes from F-8, I-9, and B-17 Islamabad residents, alongside project showcase imagery.
5. `/contact` (Contact): Phone, email, interactive contact form, exact office address, and integrated maps representation.
