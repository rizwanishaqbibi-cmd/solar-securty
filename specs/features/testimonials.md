## Project Gallery (Visual Showcase)
Instead of placeholders, the page features a responsive gallery showing solar and security installations:
* **Solar Arrays**: High-quality photographs of roof-mounted GI structures with solar modules.
* **Inverter Setup**: Neat wiring closets displaying inverters and lithium battery storage walls.
* **CCTV Feeds**: Screenshots of clear day/night monitoring feeds.

## Technical Details
* **Gallery Interaction**: Lightbox popups for images when clicked, letting users zoom into installations.
* **Layout**: Masonry or neat grid format showing customer cards alongside project images.
